## 1. Introduction
This document describes the roles and
responsibilities of the three team members
working on the Harmonie Budget Tracker
project. It ensures clear accountability for
every phase of the Research Plan Design
Build Evaluate cycle as required by the
OPSC6311 POE.

## 2. Team Roles and Responsibilities
The team is structured into three distinct
roles. Each role is assigned specific tasks
to deliver a complete and high-quality
submission that meets all POE requirements
and rubrics.

## 3. Project Manager Researcher Designer
Oversees the full Research Plan Design Build
Evaluate cycle. Leads Part 1: Researches 3
existing apps, creates the infographic
comparison, and compiles the list of
features. Develops the Planning and Design
document: app name, icon, requirements, UI
mockups, navigation diagram, and Gantt chart
project plan. Manages deadlines,
communication, and ensures the team follows
the POE instructions referencing, Turnitin,
submission requirements. Writes the
introduction, conclusion, and references for
the design document. Ensures the final
README comprehensive report is complete.

## 4. Software Developer
Builds the fully working Android app in
Kotlin Part 2 prototype plus Part 3 final
app. Implements all required features: user
login registration, expense categories,
expense entries amount, date, description,
category, photo attachment camera gallery,
monthly budget goals, category totals, local
database, graphs, progress dashboard,
and gamification badges rewards. Adds at
least 2 own innovative features as per the
design document. Creates the app icon and
final image assets. Writes clean, commented
code with logging. Initializes the GitHub
repository, commits regularly, and sets up
GitHub Actions for automated builds and
testing.

## 5. Quality Assurance Tester Documentation Video Lead
Tests all functionality on a real mobile
phone not just emulator to find bugs,
crashes, and logical errors. Verifies each
feature against the rubrics: login,
categories, entries, photo storage, budget
goals min max, period filtering, category
totals, graph, progress dashboard,
gamification. Checks UI/UX consistency
layouts, fonts, colors and handles invalid
inputs no crashes. Writes automated unit
tests for main functionality. Creates the
professional demonstration video with voice
over showing all features running on a
mobile phone compressed, uploaded as
unlisted YouTube link. Manages the README
file on GitHub adds images, documents the
two own features, includes video link.
Prepares the final APK and ensures all
submission components source code, README,
video link, research PDF, design PDF are
correctly uploaded.
